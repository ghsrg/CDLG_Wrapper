# Документація проєкту

Цей каталог містить правила, навігацію, рішення та поточний roadmap для
наукового експериментального проєкту CDLG adapter.

Починайте з [`AGENTS.md`](../AGENTS.md), потім переходьте до
[`PRINCIPLES.md`](PRINCIPLES.md) і [`INDEX.md`](INDEX.md). Читайте лише ті
документи, які стосуються поточного завдання.

Нормативним описом першого експерименту залишається
[`wrapper-design.md`](wrapper-design.md).
Ця документаційна система не замінює його і не змінює його статус.
