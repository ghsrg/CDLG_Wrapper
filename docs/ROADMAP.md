# Roadmap

## Current status

The repository is a new research project. The architecture and first-experiment
design are documented, while wrapper implementation has not started.

## Next work

1. Create an implementation plan under `docs/superpowers/plans/`.
2. Implement the external CDLG runner and configuration boundary.
3. Implement version annotation, structure export, enrichment, evidence
   generation, and strict validation in reviewable slices.
4. Add the layered tests and downstream compatibility smoke test described by
   the specification.

## Open questions

No additional roadmap questions are recorded here. Design-specific questions
belong in the specification until the approval gate is passed.

## Status discipline

Move an item forward only when code, tests, and relevant evidence support the
claim. Keep incomplete work visible as `planned`, `in-progress`, or `blocked`.
