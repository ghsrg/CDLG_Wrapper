# Decisions

Use this directory for durable architectural or repository-boundary decisions
that should remain discoverable independently of task history.

Before creating a decision record, check whether the decision already belongs in
the living design specification. Do not duplicate the full specification here.
Create a focused record only when the rationale must remain stable after the
current experiment or when the decision affects multiple future slices.

Recommended filename:

```text
YYYY-MM-DD-short-decision-title.md
```

Each record should include `Status`, `Context`, `Decision`, `Consequences`, and
links to affected specifications or implementation files.
